# MS Home Trends - Front-End App

Modern, luxury e-commerce web application for **MS Home Trends** built with React 19, TypeScript, Tailwind CSS, Lucide Icons, and Motion.

## Features
- **Luxury Brand Aesthetic:** Deep royal navy and rich gold styling
- **Category Browsing & Filter:** Filter by material, color, price, tag, rating
- **Product Details:** High-res gallery, zoom preview, customer reviews, add to cart
- **Cart & Slide-out Drawer:** Real-time totals, coupon validation, free shipping progress
- **Seamless Checkout:** Cash on Delivery & Direct Bank Transfer with slip screenshot upload
- **Admin Dashboard:** Real-time analytics, inventory management, order status tracker, Cloudinary media uploader

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```
